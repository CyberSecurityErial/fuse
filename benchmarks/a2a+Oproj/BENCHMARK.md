# A2A + O-projection Benchmark

## 口径

- BF16 Ulysses inverse A2A 后接 output projection；
- 三个人工 Golden 加五组真实 GQA 模型，六档全局序列长度，CP4/CP8，共96个 setting；
- 每个正式结果使用10次 warmup + 50次采样，每次先取跨 rank 最大延迟，再报告 p50/p95；
- 融合吞吐只计算 `2MNK`，边界耗时包含完整 inverse A2A；
- 融合入口内部 exact mismatch 非零会直接失败，不进入汇总。

### 测试设备

8张132-SM、CC 9.0、约140 GiB显存的H200级GPU。CP4固定使用物理卡 `0,2,4,5`；CP8使用全部GPU。物理卡 `1,3,6` 的SM频率上限为1500 MHz，其余为1980 MHz，因此CP4与CP8只在各自固定卡组内做公平比较。软件为PyTorch 2.9.0+cu128、Transformer Engine 2.19.0.dev0+a7aec214、NCCL 2.27.5。算子代码锚点为 `334f9d35dbd50caa06d0ff55c4067e19d132a710`。

## Shape

逻辑 GEMM 为 `[M,K] × [K,N] -> [M,N]`，其中 `M=B×S/CP`、`N=hidden_size`、`K=Hq×D`。全局序列固定为1K/4K/16K/128K/256K/512K。

## 基线如何调优

TE+NCCL 与 cuBLASLt+NCCL 对每个 setting 搜索48个 NCCL tuple：`channels={8,16,24,32}`、`chunk={128,256,512,1024} KiB`、`LL={16,64,128} KiB`。不同 NCCL tuple 使用独立 `torchrun` 进程，避免进程级参数缓存；短程1+3先选route shortlist，再搜索 Graph/eager、stream优先级与pack参数，winner固定后做10+50。cuBLASLt使用64 MiB workspace，对可运行 heuristic 做5+30本地调优。

TE Userbuffers 搜索 `comm_sm={4,8,12,16,20,24}`，再围绕入围通信SM检查3 streams、push/pull、CE/SM、pack block/warp和方向；正式候选统一10+50。

融合侧固定 `--lhs-policy auto --raster n --swizzle 1`，只把 `comm_ctas` 当外部变量：先扫 `{2,4,6,8,10,12,14,16,20,24}`，再复查短程winner相邻整数，最后取top-3做10+50。三组历史代表点直接使用v3 Golden；Llama-3-8B与Qwen2.5同物理几何复用该Golden；生产Qwen、Nanbeige和Llama-405B重新执行完整单变量标定。

## 复现

```bash
export FUSE_CP4_DEVICES=0,2,4,5
export FUSE_CP8_DEVICES=0,1,2,3,4,5,6,7
for phase in baseline-nccl-sweep baseline-mode-sweep baseline-pack-sweep baseline-formal baseline-aggregate; do
  python3 'benchmarks/a2a+Oproj/oproj_shape_bench.py' --phase "$phase"
done
for phase in fuse-comm-sweep fuse-comm-refine fuse-comm-formal fuse-calibrated-aggregate comparison-table; do
  python3 'benchmarks/a2a+Oproj/oproj_shape_bench.py' --phase "$phase"
done
python3 'benchmarks/a2a+Oproj/te_userbuffers_shape_bench.py' --phase all
```

## 如何让使用者跑到 SOTA

生产默认入口仍是 `--comm-ctas 0 --lhs-policy auto --raster n --swizzle 1`。本文极限表额外标定 `comm_ctas`，没有手工固定tile；换GPU、NVLink拓扑或新宽度时，应重复同一单变量协议。表中同几何复用只复用完全相同的 `M/N/K/Hq/D/CP/S`，不会拿相近shape代替。
