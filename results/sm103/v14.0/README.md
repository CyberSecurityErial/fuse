# SM103 BF16 前向融合：v14.0 基线 Graph 全量表

## 发布文件与复现

- `table.csv`：唯一融合结果表，192 个逻辑点；190 个测量结果、2 个显存缺项。
  同行保存 tile、comm CTA、swizzle/raster、节点/源码/二进制/环境指纹和已匹配基线配置。
- `samples.json`：上述正式候选的 max-rank 原始样本；用于重算 p50/p95，非中间搜索数据。
- `audit.json`：108 个物理 geometry 的终态回执与归档哈希，含受资源限制的失败。
- `baselines.csv`：已有唯一基线档案的 Graph 视图（576 行），保留 TEUB、
  cuBLASLt+NCCL 和纯 cuBLASLt 的数值与配置。节点和布局是键的一部分；不能跨节点拼比值。
  `table.csv` 的 QKV CP8 对照还引用验收过的节点09 sweep，因此不应只按本文件重新拼表。

依赖：CUDA 13.0、MPI、支持 SM100 collectives 的 CUTLASS。本机验证用
CUDA 13.0.48 / GCC 12，CUTLASS commit `57e3cfb47a2d9e0d46eb6335c3dc411498efa198`。
在已有工具链的非系统构建目录中，例如：

```bash
cmake -S . -B build/sm103-release -DFUSE_ARCH=sm103 \
  -DCUTLASS_ROOT=/path/to/cutlass -DFUSE_BUILD_MPI_BENCH=ON \
  -DFUSE_ENABLE_PROFILING=OFF -DCMAKE_BUILD_TYPE=Release
cmake --build build/sm103-release -j 4
# QwenDense CP8/128K。其他点按 table.csv 的几何与配置替换，不自动扩大搜索。
CUDA_VISIBLE_DEVICES=0,1,2,3,4,5,6,7 mpirun -np 8 \
  build/sm103-release/fused_bf16_mpi --world 8 --global-seq 131072 \
  --hidden 2048 --q-heads 16 --kv-heads 8 --head-dim 128 \
  --comm-sm-list 32 --qkv-policy-list m128n256k64e32 \
  --oproj-policy-list m128n128 --max-swizzle-size 4 \
  --qkv-raster along_m --oproj-raster along_n --causal \
  --input-generator gpu_philox --launch graph --timeout-seconds 300
```

MPI 按所在环境配置；运行前确认全部卡显存与计算负载。该示例以 QKV 行为目标，
同次顺带测出的 OProj 不是其独立调优结果。cuBLASLt/TE 重放还需要
[benchmark 合同中的依赖与适配补丁](../../../benchmarks/sm103/README.md)。

发布前本地 251 项定向回归通过。production/profile CUDA 构建与完整设备测量
在发布注释之前完成；之后仅增补注释、发布文档及数据，没有修改 kernel 逻辑。
本版未重新验证 SM90 的 CUDA 运行性能，不将静态迁移检查冒充设备回归。

## 测量口径

节点09；MPI一进程一卡，逐样本跨rank最大CUDA-event时间后求p50/p95；随机Philox输入、至少10次预热+50次采样、两代输入完整数值和路由校验。固定已有配置，不追加网格搜索。
历史192项（本轮已结束），本轮实测190项。缺项留空，不用旧融合数据补齐。llama31_405b、CP4、S524288两方向受显存限制。
PFLOPS均为每卡有效GEMM FLOPs/融合总耗时。TEUB、Lt+NCCL含通信；Pure Lt是单GPU cuBLASLt纯GEMM，不是经典cuBLAS；Pure%不是硬件峰值MFU。
对照只用同节点、同Graph、同布局的已验收历史基线；纯GEMM精确匹配MNK。不是本轮同时复测；缺少匹配值就留空，不跨节点计算加速比。旧Eager表不参与优化前后比较。
1K/4K仅作覆盖/回归，不作为调优重点；长序列S>=65536单列统计。
旧版提升=(旧版p50/新版p50-1)×100%，仅填写同节点、同Graph、同配置的本次改动前对照。旧全量v31是节点0a Eager，不能与本轮节点09 Graph混算提升；无匹配前值就留空。
同配置改动前后六点结果及profile证据见仓库[算子设计记录](../../../csrc/operators/sm103/README.md)的Coordinated producer / ready / copy order；六个大体积诊断trace仅保留在本地，不随版本发布。
