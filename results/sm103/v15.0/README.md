## 配置与复现

这是构建选项，不是逐 shape 自动启用的运行时策略。默认 OFF。
全表使用 BF16、tile m128n256k64e32、CTA swizzle 4、raster along_m；
每点通信 CTA、节点和两次 run ID 见 [table.csv](table.csv)。
本表的“原/新”是同节点 OFF/ON 融合路径，不是 TEUB/cuBLASLt；
历史强基线及 OProj 仍见 [v14.0](../v14.0/README.md)，本次没有重测这些基线。

```bash
cmake -S . -B build/sm103-rank-swizzle -DFUSE_ARCH=sm103 \
  -DCUTLASS_ROOT=/path/to/cutlass -DFUSE_SM103_QKV_RANK_SWIZZLE=ON \
  -DFUSE_ENABLE_PROFILING=OFF
cmake --build build/sm103-rank-swizzle -j4
```

OFF 构建省略该选项或显式设为 OFF，建议使用独立构建目录。
workspace 控制器在 fused-build 与 fused-smoke 两步均加
`--qkv-rank-swizzle` 才测 ON；默认两步均不加。按表中几何、通信 CTA、
tile、raster 和 swizzle 重放，使用 MPI Graph、gpu_philox、至少 10+50。
本版本明确拒绝 rank swizzle 与 profiling 同时开启；默认 OFF 的 profiling 可用。

- [samples.json](samples.json)：190 次运行各自首个稳定轮的 50 个 max-rank CUDA-event 样本（ms），p50/p95、半段漂移和轮号。
- [audit.json](audit.json)：相同 run ID 对应的 M/N/K、实际配置、节点、源码/环境/二进制/原始归档 SHA256。
- 原始归档在既有 `results/automation/<run-id>/` 保存；发布目录不复制完整日志、大 profile 或调优中间产物。
- 每卡 PFLOPS = `problem_gemm_flops / (p50_ms * 1e12)`；加速比 = OFF p50 / ON p50。不是硬件峰值 MFU。
- 95 点中 50 点变快、45 点变慢；长序列 47 点中 28 点变快、19 点变慢。几何平均只统计成对完整点，不填补缺项。
