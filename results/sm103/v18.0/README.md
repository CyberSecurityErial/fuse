# v18.0：OProj 运行时通信预算与吞吐归档

本版覆盖节点09（用户说明硬件为B300；实测CUDA Runtime 10.3、148 SM）、BF16输入/FP32累加/BF16输出、Graph、causal_dual_chunk_v1，以及五模型 × S=128K/256K/512K × CP4/8的30点。23点的A/B共46个候选完成两组可复现随机输入的完整数值与路由校验；7个历史缺测/OOM点保持空白，未重试。

A为v17最终CSV配置在同一v18源码、二进制和环境上的显式重放，通信预算取最终`comm_ctas`，不是旧`baseline_comm_ctas`。B经真实运行时API自动选择通信CTA，固定每点的M/N/K、heads及GEMM tile/raster/swizzle；23点全部rank的实际预算均匹配测量前冻结预测，其中9点预算改变。C已在投递前取消，本轮没有同选中预算的额外C对照，也没有新一轮五预算实测搜索。

23个有效点等权统计，B/A吞吐几何平均变化为 **−1.2087458%**；B相对历史满SM纯cuBLASLt吞吐的几何保留约 **85.28%**。已知明显退化为Qwen3-235B、CP8、512K：通信CTA **32→48**，吞吐1.276→1.140 PFLOPS，**−10.6170%**。该配对未触发半段漂移标记，但仍只有5个样本；本版不宣称自动选择普遍优于离线配置或已实现GEMM参数自动选择。

本轮采用1次预热+5次采样快测，`formal_eligible=false`，没有收敛门禁；12/46个候选、7/23个配对至少一方半段p50漂移超过5%。数值/路由verified不代表正式性能稳定性通过。Graph设备计时不含CPU首次模型查询、缓存查询或Graph构建；A/B包含预算选择效果及跨进程、执行顺序和时钟噪声，不能归因为纯API开销。

历史“优化前”取各模型最早可比归档：Llama为v14.0，其余四模型为v16.0，均为历史至少10+50；这不是统一首版基线，也不是本轮同场对照。纯cuBLASLt为同M/N/K、GPU0满148SM可用预算（`math_sms=0`）的历史Graph至少10+50纯GEMM，不含通信，未以缩减SM预算数据替代。历史与本轮输入生成协议独立，未声称随机数逐位相同。

SM90保持冻结，QKV未扩大验证范围；本归档仅支持已适配的OProj边界，不扩大到KDA六路特殊路由或新精度。

## 复现配置

仓库根目录、已有匹配v18构建与环境下，以下两条命令对应Qwen2.5-72B、CP4、128K，M/N/K=32768/8192/8192，实际用卡0/4/6/7。B使用自动入口，冻结及实测预算为32；A显式传入v17最终预算24。命令保留本轮1+5协议；此归档整理没有新增GPU测量。

```bash
python3 scripts/l20d.py run fused-smoke --node 09 --mpi --quick \
  --fused-launch graph --fused-direction oproj --experiment reproduce-v18-qwen72-auto \
  --world 4 --devices 0,4,6,7 --global-seq 131072 --hidden 8192 \
  --q-heads 64 --kv-heads 8 --head-dim 128 --auto-oproj-comm \
  --oproj-policy m128n256 --oproj-raster along_m --max-swizzle-size 8 \
  --oproj-comm-layout rows --input-generator gpu_philox --causal \
  --timeout 900 --timeout-seconds 300

python3 scripts/l20d.py run fused-smoke --node 09 --mpi --quick \
  --fused-launch graph --fused-direction oproj --experiment reproduce-v18-qwen72-explicit \
  --world 4 --devices 0,4,6,7 --global-seq 131072 --hidden 8192 \
  --q-heads 64 --kv-heads 8 --head-dim 128 --comm-sm-list 24 \
  --oproj-policy m128n256 --oproj-raster along_m --max-swizzle-size 8 \
  --oproj-comm-layout rows --input-generator gpu_philox --causal \
  --timeout 900 --timeout-seconds 300
```
